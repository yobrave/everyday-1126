# Everyday Things, Two Lines

Two-line explanations of everyday things for a ten-year-old: one vivid analogy, plus the honest limits of what it maps. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
